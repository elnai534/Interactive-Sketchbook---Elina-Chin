I liked how immediate everything was. Every time I added CSS and saw the page change right away, it felt really rewarding—almost like a little dopamine boost after finishing each step, it definitely was really fun and my favourite part of the assignments so far. I found the CSS syntax hard to remember. I kept having to think about where the braces, colons, semicolons, and selectors went. But after doing it repeatedly, it started to feel much easier and quicker to pick up. I learned that the universal selector (*) affects every element, and a selector: li only affects list items. I learned that a descendant selector: ol li, can change list items in one specific list without changing all the others. Using commas to group selectors was also useful and made a lot of sense.

I noticed that when multiple css rules affected the same element, the more specific rule could take over and override the less specific one. That helped me understand cascading: CSS - looks at which rule is more specific and where it appears in the file. Connecting both the root-level and child-level CSS also showed me how important relative paths are. When the path was wrong, the stylesheet did not load, so nothing changed. That was frustrating and i could not figure out what was not working and had spent some time troubleshooting it.
