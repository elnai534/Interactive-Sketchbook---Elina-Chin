positioning elements

Static

default, as-is behavior

Relative

this positions a child relative to its parent. by giving an element a relative position, we can place it outside the normal flow of where it would be- but it still impacts other elements

Absolute

this takes the element out of the line up and no longer impacts elements around it, BUT you have to apply position:relative to a parent container

Fixed

positioned in relation to the browser window, it just stays put!

***Sticky***

this one is a little more advanced, and we won’t get into it yet, but perhaps challenge yourself and your project to see if you can figure it out?


Next up: z-index

this is how we control layering when we are using positioning. if an element has a position, you can add a z-index, the larger the number the closer to the top.
0=bottom 100=top
think of z-index like the “bring to front” or “send to back” in design software.

Reflection

I feel like the absolute positioning made the most sense to me because the parent gives the element a clear reference point. For giving the body position: relative means the absolutely positioned overlay-wrapper uses it to work out where to sit. This connects back to the parent and child relationships from the Flexbox assignments and makes it more familiar !

I think the difference between relative and absolute positioning is that relative positioning moves an element from its normal position, but keeps its original space. Absolute positioning removes it from the normal flow, so the surrounding content does not make room for it. The circles use relative positioning inside the absolute wrapper, which made the difference easier to see.

The z-index was the most interesting part to me because it works like bringing something forward or sending it backwards in design software (layers). Layering the text above the shapes keeps it readable while still allowing the elements to overlap.

When i fixed the footer it keeps it in the same corner of the browser while scrolling. The layout needs space for it so it does not cover the last paragraph. The circle offsets also need adjusting after positioning their parent.

Going forwards, positioning could be useful for labels over my Sketchbook images. But i think I would still use Flexbox for the main layout, because too many positioned elements could overlap or become difficult to read on smaller screens.
