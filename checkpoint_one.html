Box Model

I learned the difference between margin and padding by trying it out. I have learned it before but it has always been easy to mix up for me because they do kind of the same thing but are very different once executed. when i added the borders and backgrounds, it made the box really clear as it created a lot of contrast and made it very clear what was padding and what was margin. I also learned that the background covers the content and the padding, but not the border or margin. I also learned that display is a property that can be used to change how an element is displayed on the page, and that inline elements do not start on a new line and only take up as much width as necessary, while block elements start on a new line and take up the full width available. i spent a lot of time trouble shooting when i had to add the navigation to the page because it was not working because I had added the wrong link in the header. When I changed the display property, it changed how the elements were displayed on the page, and I was able to see the difference between inline and block elements.
