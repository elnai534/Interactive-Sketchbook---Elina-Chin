Process Reflection

This assignment connected to the previous two-column lab, but this time Flexbox controlled several parts of the page I made the header, navigation, and article section flex containers. Seeing the structure was helped me understand how the navigation could be a child of the header and also a parent to its own links. I used percentage widths to divide the space,this connected back to margin and padding again, and adding space affects how much room is available for the content. I had a missing article tag that made it so that the column was not dsplaying correclty for the cat. I feel like the images was the hardest part of the assignment for me as they were all different widths so you cant just give them the same width. I used object-fit: contain to make sure the images were all the same size and lined up with the text below them. I also used flex-wrap to make sure that when the browser window was smaller, the columns would stack on top of each other instead of being squished together. Going forwards, I could use this structure to display my Sketchbook assignments as cards/boxes.
