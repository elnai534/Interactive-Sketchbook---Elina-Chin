Hierarchy: 08/27/2026

HTML is not new to me, however I am pretty rusty and this was a great refersher and honestly really fun. It has been a long time I have used pure html, and it was much needed and I feel like I have relearned a lot of the basics and some new things as well.
It has been a while since I have done web development, and I lost all my previous VS code extentions because I got a new computer. So this really made it feel brand new.
I have prior knowledge of hierarchy and syntax, and it was honestly really hard to go against those as usually proper structure and syntax is enforced and a priority.
I changed the hierarchy to put more emphasis 'Two Systems' as that is what the novel is on, and highlighted lines 22-25 because that is the intro to the two systems - that I previously highlighted.
Additionally I used the <em> tag on line 31-32 because that is where it explains exactly what System 2 does, along with 'automatically' in line 28 . I believe that this is where the basis of Daniel Kahnneman's theory is, and I wanted to highlight that.
I am pretty satisfied with my work, this is a great refresher and I feel like I have learned a lot. It took me a while to remeber how this all works, but once I did, it felt like I was flowing!
If I had more time, I would have added more text and edited the styling more to bring more emphasis - as I believe that emphasis brings emotion and meaning.
A designer definitely has a large impact on delivering information and intent, and hierarchy is really where it all starts, so this feels like a great assignment to start and warm up with!
